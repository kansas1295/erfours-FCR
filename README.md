# Daily Monitoring App: FCR, Pakan, & Indeks Performa (IP)

Aplikasi berbasis web untuk memantau performa harian peternakan ayam broiler secara real-time. Platform ini membantu peternak dan manajemen dalam mengambil keputusan berbasis data untuk mengoptimalkan efisiensi pakan dan menekan angka kematian.

## 🚀 Fitur Utama

- **Monitoring FCR Harian**: Menghitung Feed Conversion Ratio secara otomatis setiap hari untuk memantau efisiensi konversi pakan menjadi bobot daging.
- **Pelacakan Stok Pakan**: Manajemen input dan output pakan harian untuk mencegah kekurangan stok.
- **Analisis Mortalitas**: Pencatatan angka kematian harian guna mendeteksi masalah kesehatan sedini mungkin.
- **Kalkulator Indeks Performa (IP)**: Menghasilkan nilai IP secara otomatis sebagai tolak ukur keberhasilan operasional kandang.
- **Visualisasi Data**: Grafik tren pertumbuhan dan efisiensi untuk mempermudah evaluasi per periode (brooding hingga panen).

## 📊 Parameter yang Dipantau

Aplikasi ini berfokus pada indikator kinerja utama (KPI) peternakan:
- **FCR (Feed Conversion Ratio)**: Perbandingan jumlah pakan dengan bobot ayam hidup.
- **IP (Index Performance)**: Skor efektivitas produksi berdasarkan pertumbuhan, efisiensi pakan, dan persentase ayam hidup.
- **Mortalitas/Deplesi**: Persentase penyusutan populasi akibat kematian atau pemusnahan (culling).
